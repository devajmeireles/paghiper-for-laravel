Contribuição

Sinta-se a vontade para contribuir com um PR que resolva algum problema ou introduza melhorias. Será muito útil se o seu PR seguir os seguintes padrões:

  • O código do PR ser escrito em inglês, seguindo a PSR12
  • O código do PR ser formatado usando PestPHP
  • O código do PR ser analisando usando PhpStan
  • O código do PR ser testado usando PestPHP, inclusive adições ou modificações

Sinta-se à vontade para enviar o seu PR mesmo que ele não atenda as exigências acima. 😉

Ambiente de Desenvolvimento

  1. Crie um fork do repositório
  2. Clone o repositório a partir do seu fork:
git clone <url_do_repositório>
  1. Instale as dependências:
cd <pasta> && composer install
  1. Execute testes:
composer test
  1. Analise a integridade do código:
composer analyse
  1. Analise a integridade de tipagem do código:
composer type:coverage
